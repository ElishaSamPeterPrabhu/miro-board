# Project Reference Documentation

## 1. Overview
This repository is a small full-stack Nx monorepo that contains:

* **`api-server/`** – a lightweight Express server that exposes a simple REST API for managing notes grouped by columns.
* **`my-library/`** – a shareable React component library that provides reusable UI building blocks (`Note`, `Column`, `MyLibrary`).
* **`apps/miro-board/`** – a React application that consumes both the Express API and the component library to create a basic collaborative board similar to Miro.

---

## 2. Running the project locally

1. **Install dependencies**
   ```bash
   # From the repository root
   npm install           # installs workspace-wide dev dependencies

   # Install API server dependencies
   cd api-server && npm install && cd ..
   ```

2. **Start the API server**
   ```bash
   cd api-server
   node index.js         # the server runs on http://localhost:5000
   ```

3. **Start the React development server**
   ```bash
   npx nx serve miro-board
   ```

The React application will open on http://localhost:4200 and will automatically communicate with the API server on port **5000**.

## 3. REST API
The Express server implements an in-memory store so data is **not persisted** between restarts. Endpoints are namespace-scoped by **columnId**.

| Method | Endpoint                               | Description                               |
| ------ | -------------------------------------- | ----------------------------------------- |
| GET    | `/notes/:columnId`                     | Retrieve all notes for a column           |
| POST   | `/notes/:columnId`                     | Add a new note to a column                |
| PUT    | `/notes/:columnId/:noteId`             | Update an existing note inside a column   |

### 3.1  Get notes for a column
```http
GET /notes/1 HTTP/1.1
Host: localhost:5000
```
**Response – 200 OK**
```json
[
  { "id": "9b1c", "text": "Buy milk" },
  { "id": "fa22", "text": "Read docs" }
]
```

### 3.2  Add a new note
```http
POST /notes/1 HTTP/1.1
Host: localhost:5000
Content-Type: application/json

{
  "text": "New task"
}
```
**Response – 200 OK**
```json
{ "text": "New task" }
```

### 3.3  Update an existing note
```http
PUT /notes/1/9b1c HTTP/1.1
Host: localhost:5000
Content-Type: application/json

{
  "text": "Buy oat milk" 
}
```
**Response – 200 OK**
```json
{ "text": "Buy oat milk" }
```

## 4. React Component Library (`my-library`)
All public components are re-exported through `my-library/src/index.ts`, so consumers can simply import from the package root.

```ts
// Example
import { Column, Note } from 'my-library';
```

### 4.1  `<Note />`
| Prop          | Type                       | Description                                   |
| ------------- | -------------------------- | --------------------------------------------- |
| `id`          | `string`                   | (Required) Unique identifier for the note.    |
| `text`        | `string`                   | (Required) Note body/value.                   |
| `onTextChange`| `(text: string) => void`   | (Required) Callback fired on text edit.       |

Example:
```tsx
import { useState } from 'react';
import { Note } from 'my-library';

export function NoteExample() {
  const [text, setText] = useState('Hello');
  return <Note id="n1" text={text} onTextChange={setText} />;
}
```

### 4.2  `<Column />`
| Prop            | Type                                         | Description                                    |
| --------------- | -------------------------------------------- | ---------------------------------------------- |
| `title`         | `string` (optional)                          | Column heading.                                |
| `notes`         | `{ id: string; text: string }[]`             | Note collection displayed in the column.       |
| `onAddNote`     | `() => void`                                 | Invoked when the "+" button is clicked.       |
| `onUpdateNote`  | `(noteId: string, text: string) => void`     | Fired when an existing note is edited.         |

Example:
```tsx
import { Column } from 'my-library';

const notes = [
  { id: '1', text: 'First' },
  { id: '2', text: 'Second' },
];

function handleAdd() {
  // create a new note
}

function handleUpdate(id: string, text: string) {
  // update note logic
}

<Column title="Todo" notes={notes} onAddNote={handleAdd} onUpdateNote={handleUpdate} />;
```

### 4.3  `<MyLibrary />`
A placeholder component generated by Nx that simply renders a welcome message. Useful as a starting point for further shared components.
```tsx
import { MyLibrary } from 'my-library';

<MyLibrary />;
```

## 5. Miro Board Application (`apps/miro-board`)
The app stitches together the API and the library. Key code resides in `apps/miro-board/src/app/app.tsx`.

### 5.1  Helper functions
| Function     | Purpose                                                           |
| ------------ | ----------------------------------------------------------------- |
| `fetchNotes` | Fetch existing notes for all columns at start-up.                 |
| `addNote`    | POST a new note via the API and update local state.               |
| `updateNote` | PUT an edited note via the API and update local state.            |

All three functions rely on the endpoints documented above and demonstrate canonical usage of the API.

### 5.2  Application flow
1. On mount, `fetchNotes` pulls data from the server.
2. The UI renders a set of `<Column/>` components.
3. Creating or editing a note triggers an API request (`addNote` or `updateNote`).
4. Local component state is synchronised so the UI stays responsive even before the server responds.

## 6. Extending the project
* Swap the in-memory store for a durable database (e.g. SQLite, PostgreSQL).
* Add **DELETE** `/notes/:columnId/:noteId` to support removing notes.
* Extract API calls in the React app into a reusable SDK or React Query hooks.
* Publish `my-library` to a private NPM registry to share the components across workspaces.
